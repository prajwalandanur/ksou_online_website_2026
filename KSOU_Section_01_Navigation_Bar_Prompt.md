# Website Design Language

The website should look like a **premium educational platform**, not a traditional government website.

The design inspiration should come from the latest **Online Manipal** website.

However, **do not copy** their design.

Instead, capture the same feeling:

- Premium
- Elegant
- Minimal
- Spacious
- Trustworthy
- Modern
- Conversion focused

The website should immediately communicate professionalism and trust.
